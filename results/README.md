# Experiment results

`metrics.csv` and the four PNGs are generated by running
`notebooks/f1_race_prediction.ipynb` or `run.py`. The current files were refreshed
by the notebook rerun; they are no longer the historical output files originally
extracted during the refactor.

`metrics.csv` contains all nine model variants at full calculated precision. The
notebook displays the same comparison rounded to four decimals. The best row is LightGBM
LambdaMART (tuned): NDCG@10 0.9342, Top-5 overlap 80.8333%, and winner accuracy
45.8333%. The evaluation covers 479 driver–race records in 24 races during 2024.

## Metrics

- **NDCG@3, NDCG@10, NDCG@All:** mean per-race scikit-learn NDCG using relevance
  `max(25 - positionOrder, 0)`. Evaluation uses these relevance labels directly;
  the rankers retain their original training gain settings.
- **Spearman_Rho:** mean correlation between actual and predicted race positions.
- **Winner_Acc (%):** percentage of races whose predicted winner won.
- **Podium_Hit (%), Top5_Hit (%):** mean fraction of actual podium/top-five drivers
  recovered in the predicted podium/top five, expressed as percentages.
- **Rank_MAE, Rank_RMSE:** pooled errors between actual positions and positions
  induced by sorting each model's scores within each race. These are not the
  regressors' raw prediction errors.

Higher is better except for Rank_MAE and Rank_RMSE. For regression models, raw
predictions are negated before ranking because a lower finishing position is
better.

## Saved figures

| File | Contents |
| --- | --- |
| `feature_correlations.png` | Numeric feature correlations with finishing position |
| `feature_distributions.png` | Distributions and skewness of six historical features |
| `grid_vs_finish.png` | Finishing-position distributions by starting grid |
| `ranking_quality_2024.png` | Per-race Spearman correlation and actual vs. predicted positions |

The first three plots use the cleaned modern-era data before category grouping
and grid-zero replacement, matching the original notebook's EDA order.

Running `python run.py`, or all cells of the cleaned notebook, replaces these
artifacts with fresh outputs. CSVs retain full calculated precision. Use
`python run.py --output-dir results/new_run` to retain the current saved files.
The original environment was not locked, so rerun results can vary with package
versions. The methodological limitations in the project README also apply to
these scores.
