# Experiment results

`metrics.csv` and the four PNGs are generated by `run.py` or by running all cells of `notebooks/f1_race_prediction.ipynb`. The files currently here come from the latest notebook run.

## Metrics

`metrics.csv` has one row per model variant (nine in total) at full precision. The notebook shows the same table rounded to four decimals. The best row is LightGBM LambdaMART (tuned): NDCG@10 0.9342, Top-5 overlap 80.8333%, winner accuracy 45.8333%. All rows are evaluated on the 479 driver–race records across the 24 races of 2024.

Column definitions:

- **NDCG@3, NDCG@10, NDCG@All:** mean per-race scikit-learn NDCG, with relevance `max(25 - positionOrder, 0)`. The rankers were trained with their own gain settings, but evaluation uses these relevance labels directly.
- **Spearman_Rho:** mean correlation between actual and predicted race positions.
- **Winner_Acc (%):** percentage of races where the predicted winner actually won.
- **Podium_Hit (%), Top5_Hit (%):** mean fraction of the actual podium (or top five) that appears in the predicted podium (or top five), as a percentage.
- **Rank_MAE, Rank_RMSE:** pooled errors between actual positions and the positions you get by sorting each model's scores within a race. These are not the regressors' raw prediction errors.

Higher is better for everything except Rank_MAE and Rank_RMSE. Regression outputs are negated before ranking, since a lower finishing position is better.

## Regenerating

Running `python run.py` or the full notebook overwrites these files. To keep the current ones, write the new run elsewhere:

```bash
python run.py --output-dir results/new_run
```

The environment isn't locked to exact package versions, so reruns can differ slightly. The [limitations in the main README](../README.md#limitations) also apply to these scores.
